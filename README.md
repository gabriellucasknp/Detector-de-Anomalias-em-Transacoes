# Detector-de-Anomalias-em-Dados-de-Transa-es
Pipeline end-to-end de detecção de anomalias em transações financeiras com Isolation Forest, DBSCAN e Z-Score. Processamento distribuído com PySpark, API REST em FastAPI, dashboard interativo em Plotly e deploy na AWS (ECS Fargate + RDS) via Terraform e GitHub Actions.  Python PySpark Scikit-Learn FastAPI MySQL Docker AWS Terraform
